# TuxunGo 2.56.0

## 新功能

- **复盘「整局讲评」**：复盘分析完成后，胜率图下方会多出一张讲评卡，不用再自己一手手翻着找问题：
  - **转折点**：全场胜率摆动最大的一手，前后黑方胜率一目了然；
  - **恶手清单**：最严重的 3 步恶手逐条列出——丢了多少胜率、AI 当时的一选是哪一步；点任意一条直接跳到那一手的位置，接着就能试下、看变化；
  - **全场总账**：黑方/白方各有多少次恶手、几次妙手，发挥稳不稳一眼看清；
  - 全场没有大恶手时，讲评卡会直接说明双方发挥稳定。
- 讲评完全复用复盘分析已有的逐手数据生成，不额外调用引擎，不增加等待时间；对局时录好的棋谱、刚导入的 SGF 棋谱，分析完一样有讲评。

## 其他

- 单元测试增至 73 个用例，新增整局讲评汇总的 2 个用例。
