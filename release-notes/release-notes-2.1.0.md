# TuxunGo 2.1.0

## 稳定性

- **引擎异常自动恢复**：对局中 KataGo 引擎进程如果意外退出，App 会自动重启引擎并重试这一步，不再直接卡住或退回手动；同一手棋连续失败两次才会提示出错并转手动，局面和已下手数不受影响。

## 分析增强

- **分析深度可切换**：分析面板下新增「换个深度重算」——快速（秒出，用来扫一眼候选）、标准（更稳）两个档位，加上原有的深度分析，赶时间还是求精确自己选。
- **复盘新增高精度分析**：整场补算时多了一个高精度选项（每手 250 次访问），胜率和目差数字最可靠，适合认真复盘关键对局；快速、精准两档保留。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
