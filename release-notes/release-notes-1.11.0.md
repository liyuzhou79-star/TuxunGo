# TuxunGo 1.11.0

（包含原定 1.10.0 的全部内容：1.10.0 的安装包因故未能交付，直接并入本版。）

## 新功能与优化

- **死活题新增「倒脱靴」**：先扑一子进眼位，白棋提掉之后，回到同一点把整块十三子全部提掉——围棋里最有名的提子技巧之一。题库现有 7 题，解法全部经过规则推演逐手验证。
- **死活题可只看未解**：题目列表新增「只看未解」开关，刷题时不用在一排 ✓ 里翻。
- **文件夹可以改名了**：棋谱库选中文件夹后可以重命名。
- **自动保存可以一键清空**：「自动保存」文件夹里攒多了，选中它就能一键清空（会先确认；收藏到其他文件夹的棋谱不受影响）。
- **全屏模式也能暂停棋钟**：全屏对局 / 观战时右上角新增暂停按钮，和普通模式一致，暂停时棋钟冻结、棋盘锁定。
- **复盘图可关目差线**：复盘页新增「显示目差」开关，只想看胜率曲线时把目差线关掉，图更清爽。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
