# TuxunGo 2.18.0 更新说明

## 新功能

- **内置双模型**：模型库现在自带两个模型，开箱即用，不用再另外下载：
  - **轻量模型**：速度快，日常对局和分析都够用；
  - **强力模型**：棋力更强，形势判断和数目更准，思考稍慢。
  在模型库里随时切换，对局中也能在 AI 托管面板里给黑白双方分别指定。
- **模拟人类落子**：AI 托管面板里为任意一方打开后，这一方改用专门学习真人棋谱的模型来选点，落子风格像真人高手；同时有强力搜索兜底，真要下出大漏招会被拦下来换掉——像人，但不会故意下错招，思考强度也不打折。想和「像人的对手」练棋，或者看两台 AI 用真人风格对打，都可以试试。

## 说明

- 三个内置模型文件让安装包变大了（约 220 MB），换来的是装上就能用最强判断和真人风格，不用再折腾下载和导入；更大的模型仍可在模型库自行导入。
- 之前改过内置模型昵称的用户，名字会保留；默认名改为「轻量模型」。
