# TuxunGo 2.23.0

## 新功能

- **停一手后自动数目**：双方连续停一手终局后，不再直接弹出一个把所有棋子都当活棋的粗算结果，而是自动进入终局数目——死子由引擎先标好（多数时候复用刚算好的结果，瞬间完成），你检查无误点「确认数目」即可，也可以点开某个棋块整块改判。认输、超时的终局不受影响；AI 表演赛的系列赛则会静默采用判定结果，直接开始下一局。
- **棋谱库缩略图**：棋谱列表里每局棋左边多了一张小棋盘图，画的是这局的终局局面。找一局棋不用再逐个点开看标题了，扫一眼图就知道是哪盘。
- **落子放大镜**：开启「确认落子」时，选好落子点后，棋盘角上会出现一个放大镜，把落子点周围 5×5 的区域放大显示——大棋盘上棋子密密麻麻，再也不用担心点错一格。
- **AI 托管可交换双方**：AI 托管面板里新增「交换双方设置」，黑白的模型、强度、定级一键互换，表演赛换边不用再逐项重设。

## 优化

- **形势判断随下随判**：形势判断打开过一次之后，之后每落一手，面板会自动换成最新局面的判断（数据来自后台已经算好的分析，不重复计算），不用再手动关掉重开。
- **棋谱库按结果筛选**：列表上方多了「全部 / 黑胜 / 白胜」筛选，想找自己赢的棋或某一方获胜的对局，一点就出来。
- 死活题本想再扩充两题，候选题（直六、板六眼形）经逐手验证发现「下哪都赢」——棋形本身已是死形，没有唯一手筋可学，达不到现有题目的质量标准，故本期不上新题，维持 8 题。
