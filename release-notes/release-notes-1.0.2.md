# TuxunGo 1.0.2

## 修复

- **修复分析/判断可能永久卡在「分析中」的问题**：此前在分析进行时点「终局数目」等操作，会让先开始的分析回调被静默吞掉，界面从此一直显示分析中、判断中，只能重开应用。现在各操作互不干扰，状态一定会正确复位。
- **引擎无响应时不再无限等待**：分析引擎和对弈引擎的等待都改为分段检查——引擎进程一旦退出，立刻报错并给出引擎自己的诊断信息；引擎卡死超过时限会被自动结束，下一次操作自动换新引擎，不再越卡越死。
- **取消分析立即生效**：以前取消时结束引擎的动作排在卡住的任务后面，等于没取消；现在取消会立刻结束引擎进程，卡住的分析半秒内退出。

## 优化

- **形式判断改为开关式按钮**：判断完成后按钮变成填充色的「关闭形式判断」，点一下即可收起判断结果；判断进行中显示「判断中…」。全屏模式下同样适用。
