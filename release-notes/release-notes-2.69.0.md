# TuxunGo 2.69.0

这一版做 UI 细节总查：逐页核对滚动、文字、深色模式和动效，修掉查出来的问题。

## 修复

- **新手引导页可以滚动了**：引导的每一页以前是固定排版，屏幕矮一点的手机上，长文字会被截断、读不到底。现在每页都能上下滑动读完，小屏和大字体下都不再丢字。

## 核对结论（无问题，未改动）

- **其余页面的滚动**：对局、复盘、设置、棋谱库、死活题、摆棋、猜一选、实体棋钟、战绩、模型共十个页面逐页确认——内容超过一屏时都能滑到底，长文字自动换行、不截断、不需要横向滑动。
- **深色模式**：三套主题（樱粉、抹茶、靛蓝）都配有完整的深色配色；棋盘、棋子这类固定颜色只出现在棋盘场景里，不影响界面文字的对比度。
- **动效时长**：全 App 动画时长过了一遍，最长的是「绝」徽章的轻微呼吸（约 0.95 秒）和棋谱库加载微光（0.8 秒），都是装饰性的，不阻挡任何操作；其余交互动画都在 0.2 秒上下。
