# TuxunGo 2.60.0

## 界面全面升级

这一版把全 App 的界面统一升级为游戏产品的质感：有深度、有材质、排版成体系，而不是通用模板的样子。

- **棋盘坐进木框**：对局、复盘、猜一选、死活题、摆棋——所有页面的棋盘都嵌进胡桃木色边框，带内侧斜面线，棋盘不再是浮在页面上的一张图（开启「棋盘铺满屏幕」时仍是无框满幅）。
- **对局双方信息条**：黑白双方的头像换成按真实棋子画法绘制的棋子（带高光和体积感），信息条加了边框与阴影，轮到谁下棋高亮更明确。
- **卡片体系统一**：主页、菜单、个人统计、复盘、模型库等页面的卡片统一为带边框和柔和阴影的深度卡片；主页顶部改为品牌卡片，主页与菜单的入口卡片图标坐进主题色底板。
- **主按钮质感化**：「开始对局」、新手指南的翻页键等主按钮改为纵向渐变＋顶部高光边＋按压下沉的质感按钮；棋盘过大、AI 不支持时仍是红色警示样式。

## 其他

- 本版只有界面与视觉更新，功能、引擎与数据与 2.59.0 完全相同；深色模式与三套主题色照常工作。
