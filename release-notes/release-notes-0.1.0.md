# TuxunGo 0.1.0（测试版）

TuxunGo 的第一个公开测试版：完全免费、开源的 Android 围棋应用，内置 KataGo 引擎，装好就能和 AI 对弈、让 AI 给你指点。

## 主要功能

- **三种对弈模式**：人对人（本地双人）、人对 AI、AI 对 AI（可暂停，暂停时可分析局面）
- **AI 推荐落点**：对局中点「AI 分析」，棋盘上标出前 5 个候选点，一选为蓝色实心标记；每个候选带胜率与访问次数，点开可看变化图
- **局势判断**：胜率条、领先目数、地盘估算，并可在棋盘上按归属给空点着色
- **高自由度棋盘**：宽、高可分别在 5–25 路之间任意选择（19×19、13×13、9×9 以及 13×9 等矩形棋盘），支持让子与中国规则数目
- **模型库**：内置 KataGo 官方 10 层网络；也可以上传自己的 KataGo 模型文件（.txt.gz / .bin.gz），App 会校验文件完整性、解析模型结构，并用引擎实测加载通过后才加入模型库
- **棋谱导出**：对局可导出为 SGF 文件保存在本地

## 说明

- 这是测试版（0.x），功能还在快速迭代，欢迎在 Issues 里反馈问题和建议
- 需要 Android 10 或以上、arm64 设备
- 全部计算在本机完成，不需要联网，没有账号，不收集数据

## 安装

下载下方的 APK 直接安装即可。首次安装时系统可能提示「未知来源」，在设置中允许本次安装即可。
