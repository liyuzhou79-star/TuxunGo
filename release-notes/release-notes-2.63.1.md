# TuxunGo 2.63.1 更新说明

## 优化

- **分析标记改回实心，质感升级**：上一版的空心圈标记换成实心圆点——AI 一选紫色、二三选白色、人类选点橙红色，都带渐变、阴影和左上高光，像小玻璃珠落在棋盘上，数字压在正中；人类一选和 AI 一选落在同一点时，那个点照旧会发光呼吸。
- **形势判断面板整理**：面板收进卡片，结论、占比条、明细、可信度之间加了分隔线，强力模型的下载建议单独成段，不再和正文挤在一起。
- **AI 分析面板整理**：同样收进卡片。默认只显示胜率条、胜率与领先目数、一句话点评（和「绝」提示）；「显示」开关、分析范围、比分范围、一选与人类选点明细、地盘估算都收进「展开」里，分组之间有分隔线；删掉了和「深度分析」重复的快速/标准重算按钮。打开分析后下方不再乱成一团。
