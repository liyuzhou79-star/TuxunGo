# TuxunGo 2.0.0

## 界面大换新

- **主界面重新排版**：顶部是新的应用标志区；对弈模式改成三张可选卡片（人对人 / 人对 AI / AI 对 AI，各带一句说明，选中高亮）；训练（猜一选、死活题）与资料（棋谱库、我的数据）改成并排卡片网格，成绩和进度直接写在卡片上，一眼就能看到。
- **对局页新增双方信息卡**：棋盘上方是黑白双方的卡片——谁执子（你 / 对方 / 具体模型名）、提子数、各自的剩余时间都在卡上；轮到谁下，谁的卡片就高亮描边；AI 思考时卡片上会显示「思考中」；进入读秒的一方时间会变红提醒。
- **开始对局按钮加大**，快速开始里的「19 路标准局」改为填充主按钮，最常用的开局更好点。

## 新棋盘皮肤

- 新增「月白石」：浅灰白石面配灰色纹理，清爽耐看，在设置 → 棋盘样式里切换，设置页有实时预览。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
