# TuxunGo 1.4.0

## 新功能与优化

- **主题色三选**：设置里新增「主题色」——樱花粉、抹茶绿、靛蓝，点一下整个 App 立刻换色，不用重启。
- **复盘关键点巡览**：复盘页新增「上个关键点 / 下个关键点」按钮，在恶手、妙手和全场关键手之间一键跳转，不用拖着曲线找。
- **棋钟读秒次数可调**：开局设置里，读秒次数可以在 3 次和 5 次之间选（每次 30 秒不变），选择会被记住。
- **死活题随机抽题**：死活题页新增「随机一题」，优先抽还没解出的题，刷题不用自己翻。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
