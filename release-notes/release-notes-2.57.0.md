# TuxunGo 2.57.0

## 新功能

- **个人统计页新增「棋力自测」**（主页点吉祥物 5 下进入统计页）：根据 App 里已有的数据，给出一个大致的棋力区间：
  - 主要依据是你和**定级 AI** 的交手记录——赢过最强的是哪一档、在那一档保持全胜还会往上估、暂时没赢过则按打过的最弱档位往下估；
  - 死活题完成度作为辅助依据；完全没有定级记录时，做完大部分死活题也能得到一个粗略估计；
  - 每条依据都会逐条列在卡上（战绩、完成度），估得准不准、为什么这么估，一眼看清；
  - 数据不足时不硬估，会提示先去打一盘定级对局。
- 这是按 App 内数据得出的参考区间，不是正式段位认定；多打几盘不同档位的定级局，估计会越来越靠谱。

## 其他

- 单元测试增至 78 个用例，新增棋力估计的 5 个用例。
