# TuxunGo 2.55.0

## 优化

- **形势判断改为自适应两段判断**：以前每次判断都按设置里的计算量（默认 800）一算到底，局面再清楚也要等全程。现在先用少量计算（200）快速估算一遍：如果棋盘上大部分区域的归属已经明确，这个结果就是最终结果，判断立刻完成；只有归属不清的空位还很多（局面还在争夺中）时，才自动接着按完整计算量深入再算一遍，并实时更新面板。
  - 中后盘定型局面：出结果明显更快，强力模型下差距尤其大；
  - 复杂对杀、乱战局面：仍按完整计算量判断，精度不打折；
  - 判断过程中落子或关掉面板，深入计算会自动作废，不会弹出过期结果。

## 说明

- 设置 → 形势判断里的「计算量」仍是深入判断的上限，行为不变。
- 新手指南的「看懂形势判断」一页同步补了两段判断的说明。
