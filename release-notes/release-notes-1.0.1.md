# TuxunGo 1.0.1

## 新功能

- **复盘秒开**：对局进行时，每一手的胜率、目差和 AI 一选已在后台悄悄算好并存下。终局打开复盘时直接看曲线，只补算极少数缺口，不用再等整场分析。棋谱库里没有预存数据的老棋谱，打开时会让你选「快速分析」或「精准分析」，分析结果会自动缓存，下次打开直接看。
- **对局自动保存**：对局一结束，会自动存一份到棋谱库的「自动保存」文件夹，不会再因为忘了点收藏而丢棋。
- **带解说棋谱导出**：复盘页可一键复制带逐手胜率注释的 SGF，粘贴到任何棋谱软件里都能看到每一手的胜率变化和恶手/妙手标记。
- **快速开始**：主页新增一键开局：9 路快棋、19 路标准局、AI 表演赛，参数都按常用配置设好。

## 优化

- 复盘页按钮改用填充色，上手更清楚；曲线图的图例改为图形符号（色线、色块、圆点），并有明确的拖动提示。
- 曲线游标加粗并带手柄圆点，按住拖动跳到任意一手更顺手。
- 对局中的自动形势分析略微降档，手机更省电，数据精度不受影响。
