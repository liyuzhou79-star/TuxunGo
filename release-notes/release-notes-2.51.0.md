# TuxunGo 2.51.0

这一版主要来自真实使用中的反馈：修掉三个实际毛病，再把棋盘、复盘和分析的手感整体打磨一遍。

## 新功能

- **新默认棋盘「米黄木纹」**：浅米黄底色配细腻木纹，看久了不累眼；原来的榧木实纹保留，在设置里随时可换回。
- **棋盘铺满屏幕**（设置 → 对局与操作）：打开后棋盘边直接贴到屏幕边，铺满时自动隐藏坐标，棋盘保持正方形不变形。对局和复盘都生效。
- **落子放大镜开关**（设置 → 对局与操作）：待确认落子时角上的 5×5 放大小窗改为默认关闭，需要时再打开。
- **复盘自动播放**：打开棋谱点「自动播放」，棋谱自己一手手往下走；默认 1.2 秒一手，另有 0.6 秒 / 2.0 秒两档，手动翻页会自动暂停。
- **连续分析可选范围**：连续分析新增「双方 / 只黑 / 只白」，可以只在一方行棋时自动分析，省电也少打扰。

## 优化

- **形势判断着色更实**：引擎对「被一方围定、但理论上还能打入」的区域原本给色很保守，角上常常一片空白。现在展示时会把这类已定型区域的颜色加深到应有的程度，未定型区域保持干净；数目和死子判定不受影响。
- **连续分析跟得上手速了**：快速落子时上一次分析被取消后，现在会自动接着分析新局面，不用再手动补点；分析间隔也更短、单次计算更轻。
- **开始对局改为淡入过渡**：不再横向滑入，点下「开始对局」直接稳稳进入棋盘。
- **开局设置页可折叠**：对弈模式、用时、棋盘大小、让子与贴目分成可折叠的四组，不用每次面对一整页选项；所有选项的选中状态改为实心强调色，一眼能看出当前选择。
- **猜先改版**：不再假装抓子猜单双，点「随机分黑白」立刻随机分好，开局直接生效。
- **吉祥物新笑脸**：眼睛和嘴巴重画，更圆润亲切，小白子伙伴也有了微笑。
- **落子声换回最初版**：恢复 App 最早使用的那记落子声（设置里仍可换其他音效）。

## 修复

- 点对局上方的形势走势小图会直接闪退，现已修复（走势大图改按完整手数对齐绘制）。
- 形势判断开着时点「AI 分析」，分析结果不显示、必须先关掉判断；现在点分析会自动关掉判断并正常显示选点。
- 棋谱复盘时棋盘上下颠倒（与对局时方向相反），现已修复：复盘固定按对局时的方向打开，白方视角仍可在复盘内手动切换。
- 「复盘试下（分支探索）」改短名为「试下」。

## 其他

- 单元测试增至 61 个用例，新增展示归属加深与走势标记的防崩溃用例。
