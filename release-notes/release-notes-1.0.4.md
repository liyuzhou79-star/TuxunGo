# TuxunGo 1.0.4

## 新功能

- **猜一选训练**：全新的练棋模式。AI 自对弈逐手推进，每一手先由你猜 KataGo 的第一选择：点棋盘选点、再点一次确认，也可以猜「停一手」。猜中一选 +3 分，猜中二、三选 +1 分，还有连对计数。揭晓时会把前五候选标在棋盘上，并给出当前局面的黑方胜率；点「下一题」就落下 AI 的一选继续。支持 9 / 13 / 19 路，随时重新开始。入口在主页的「猜一选训练」卡片。

## 说明

- 猜一选使用当前选中的模型出题；换更强的模型，题目就更接近高手思路。
- 本版本为测试版（调试签名）。正式版将使用与 0.1.0 测试版不同的签名：升级时需要先卸载再安装一次；正式版之后的所有版本可直接覆盖升级。
