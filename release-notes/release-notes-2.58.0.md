# TuxunGo 2.58.0

## 新功能

- **复盘每步可看形势判断明细**：复盘页点「看这步的领地」后，除了棋盘上的领地着色，下方会多出一行这一步的判断明细——按同一份领地数据估算死子，再用中国规则数一遍：黑方活子＋空、白方活子＋空＋贴目，以及当前领先方和领先目数。翻到哪一手，就能看哪一手的账，不用再切回对局页打开形势判断。
- 明细完全复用领地分析已算好的数据，不额外调用引擎；领地结果仍按手数缓存，同一手反复看是秒开。

## 说明

- 死活题本轮尝试扩容，但候选题目都没能通过「第一手必须是唯一妙手」的求解器逐手验证（有的形状其实已经死了、怎么下都赢，有的和已有题型重复），宁缺毋滥，题库保持现有 8 道已验证题目。
