# TuxunGo 2.54.0

## 新功能

- **SGF 导入**：棋谱库右上角新增「导入」，两种方式——从文件选择 .sgf，或先把 SGF 文本复制好、再从剪贴板导入。
  - 支持一份文件里包含多局棋谱（会全部导入，包括本 App 自己「导出全部」生成的文件）；
  - 支持让子局（让子棋子与让子数）、摆子局面（预置黑白子与先行方）、矩形棋盘；
  - 棋谱里的变化图只取主线导入；
  - 导入前会用规则引擎逐手回放校验：手顺对不上的棋谱不会整盘丢弃，而是按能对上的部分存入并给出提示；
  - UTF-8 与 GBK 编码的文件都能读。
- 导入的棋谱会出现在棋谱库里（类型标记为「导入棋谱」），点开就能像自己的对局一样复盘、用 AI 分析和形势判断。在其他平台下的棋、下载的职业棋谱，都能导进来研究了。

## 其他

- 单元测试增至 71 个用例，新增 SGF 导入解析的 10 个用例（主线与变化、多局文件、让子、摆子、矩形棋盘、非法手顺截断、结果文案）。
