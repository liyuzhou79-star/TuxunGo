# TuxunGo 2.70.0

这一版修死活题训练里三个会让人以为「棋盘坏了」的落子问题——都是一次落子链路自查里找到的。

## 修复

- **点到落不了子的点，现在有反应了**：以前在死活题里点到已经有子的点、或下进去会被提掉的禁着点，棋盘毫无反应，看着就像点不动。现在会轻晃一下棋盘，并写明这个点为什么下不了。
- **看完演示正解，棋盘不再锁着**：以前演示结束后棋盘一直处于锁定状态，要找到换了样的「自己试一次」按钮才解锁，很容易被当成卡死。现在演示一结束就自动重开一局，棋盘立刻可以自己下。
- **应招的半秒里不再能搅乱局面**：答对一手后对方应招的那半秒，「提示」和「演示正解」以前还能点，会把正在进行的应招搅乱。现在这半秒里这两个按钮先禁用，应招走完恢复。
