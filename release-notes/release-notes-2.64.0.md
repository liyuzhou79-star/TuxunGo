# TuxunGo 2.64.0

这一版全部来自真机使用反馈：标记、面板、棋盘显示和走势图都按实际下棋时的感受重新打磨了一遍。

## 新功能

- **选中点浮标**：用点选确认落子时，如果选中的点正好是 AI 的一选、二选或三选，棋盘上方会浮出一个小标签告诉你；选中的是定局手时，浮出的是红色「绝」。它只是悬浮提示，不挡棋盘，也不用点掉，落子或改选后自动消失。
- **走势图单边查看**：局内走势改成一次只看一方。点走势条上的「看 黑/白」切换，胜率线、目差线和头部的胜率数字都只显示选中那一方，图面干净很多；点开的大图走势同理。

## 优化

- **候选标记改半透明**：一选（紫）、二三选（白）、人类选点（橙红）的圆点都改成半透明，棋盘木纹和棋子能隐约透出来，不再是一坨实色盖在棋盘上；「绝」字徽章改成红色实心圆盘配白字，更醒目。
- **分析面板再整理**：候选列表、变化图和「地盘显示 / 深度分析 / 就下这步」这些常用的直接摆在外面；显示开关、分析范围、人类选点、比分范围等次要内容收进「展开」，并删掉了和候选列表重复的一选文字行。
- **形势数字不再闪没**：顶部形势条和双方玩家卡片改成「有新数据才更新」——新一手分析没算完时，上一手的数字先留着，不会闪成空白，快棋和 AI 对 AI 对局时也能看清。玩家卡片上的「提子」同时换成了更实用的「目数」。
- **棋盘默认全屏宽**：棋盘默认贴满屏幕左右、去掉周围一圈深色框，坐标默认关闭（设置里随时可以打开）。
- **按钮文字单行显示**：「形势判断」「终局数目」等按钮的文字不再被挤成两行或错位（顺带修正了「形式判断」的错别字）。

## 规则调整

- **双方都停一手不再自动终局**：停一手只是停一手，想终局请点「终局数目」由双方确认。AI 对 AI 对局不受影响，双停仍会自动进入数目收官。
