# TuxunGo 2.15.0 更新说明

## 新功能

- **专注模式**：对局里新加了「专注」开关（顶栏就有，开局设置里也能提前打开）。打开后棋盘上不再显示胜率条、一选候选、实时形势和 AI 分析面板——只剩棋盘和棋子，专心下棋。对局时的后台分析不受影响，终局打开复盘，胜率、妙手、变化图一样不少。
- **实体棋盘棋钟**：两个人用真棋盘下棋时，手机可以当棋钟。主页「资料与工具」里打开，选好时间（5/10/20/30/60 分钟）和读秒次数，点开始，黑方先行；下完一步点自己这边，时间就交给对方。主时间用完进读秒，读秒少一次会响一声、震一下；超时判负，可暂停、也可重置。不用联网、不用引擎，纯计时。

## 说明

- 本版为测试版（2.15.0），可直接覆盖安装上一版。
