# TuxunGo 2.4.0

## 新内容

- **死活题第八题「点眼杀」**：白棋一条直三眼位，黑点正中心破眼——补哪一头都拦不住。解法已用规则推演逐手验证（含唯一性），归入初级。
- **新手指南**：第一次打开 App 会有三页简短指南（对弈、分析复盘、训练与模型）；看过就不再打扰，主页底部点「新手指南」可随时重看。
- **长按图标快捷入口**：长按桌面上的 TuxunGo 图标，多了「快速对局」（直达 19 路人机对局，有未下完的局则先打开它）和「猜一选」（直达训练）两个快捷方式。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
