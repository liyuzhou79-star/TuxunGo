# TuxunGo 2.3.0

- **我的数据补上错题进度**：训练进度里新增「猜一选错题待复习」计数，错题攒了多少一目了然。

- **仓库 README 中英文同步更新**：补齐 2.0 以来的新界面、双方信息卡、月白石皮肤、错题本、每日一题、模型测速、引擎自动恢复等功能说明。
