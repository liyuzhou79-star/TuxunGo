# TuxunGo 2.6.0 更新说明

## 新功能

- **长按图标新增「每日一题」**：长按桌面图标，除了快速对局和猜一选，现在还能直达今天的死活题——和主页卡片推荐的是同一题（优先从没解开的题里按日期轮换）。

## 优化

- **全屏模式也能分享局面**：全屏看棋时顶栏加了「分享」，不用退出全屏就能把局面图发出去。
- **复盘分享带胜率**：复盘页分享的局面图，说明文字会带上这一手的黑方胜率（已分析过的对局），发给朋友时形势一目了然。
- **错题本可清空**：猜一选的错题本旁加了「清空错题本」，练完一轮想重新开始时不用一道道攻克了。

## 说明

- 本版为测试版（2.6.0），可直接覆盖安装上一版。
