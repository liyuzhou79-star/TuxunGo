# TuxunGo 1.2.0

## 新功能

- **死活题训练（新模式）**：首页新增入口。首批 4 道题——紧气、双吃、共气对杀、征子——做对一步，对方自动应招；有提示、有讲解，解题进度会一直保存。每道题的解法都经过规则推演逐手验证，关键步唯一，填错的那口气为什么错，讲解里写得明明白白。
- **复盘分支可存为棋谱**：1.1.0 的「试下」分支现在能一键存进棋谱库，好想法不会试完就丢。
- **对局结束有「全场转折」**：终局弹窗会指出整盘胜率波动最大的一手，点一下直接跳到那一手开始复盘（基于对局时后台实时记录的数据）。
- **对局页迷你胜率条**：形势行上方多了一条细长的黑白胜率条，扫一眼就知道谁占上风。
- **首页最近棋谱**：首页底部直接列出最近 3 局，点开就进复盘，不用先进棋谱库翻找。
- **让子自动贴目**：选 2 子以上让子时，贴目自动从 7.5 改为 0.5（让子棋的惯例）；自己手动填过的贴目不会被动。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
