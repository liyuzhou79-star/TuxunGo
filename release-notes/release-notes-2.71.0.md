# TuxunGo 2.71.0

## 「绝」判定重做：一局可以有多个标记，每个都有理由

以前「绝」只有一个，而且判得太轻：胜率一冲到 99%，后面步步都是「绝」，标了等于没标。这一版把整套定局标记重做：

- **红色「绝」= 全局定局**：胜率长时间稳在 94% 以上、地盘基本分完、落后方把剩下的空全占掉也超不过、优势方地盘里没有能打进去的地方——全部满足，且之后两手仍然成立，才把定局的那一手钉上「绝」。官子全部收完的那一手、以及从大落后逆转并稳住十几手的那一手，也会判「绝」。
- **蓝色「定」= 局部定型**：一条大龙被掐断最后活路、大龙最后的弱点被补上、一片区域的归属定死——只管那一片，标蓝色的「定」，和全局的「绝」分开。
- **绿色「销」= 消劫**：谁把劫消了，消劫的那颗子就标「销」，对局进行中当场出现，一局可以有很多个。

所有标记都是扁平小圆盘 + 书法体字（和原来的「绝」一个样式），钉上之后一直留在子上。判定宁可晚两手、不可乱标：归属要连着几手都定住了才算数，一晃而过的假定型不会留标记。

复盘里每个标记都能查理由：点棋盘上带标记的子，棋盘下面写明为什么判它；「整局讲评」里每条标记单独列出（第几手、哪种、为什么），点一条直接跳到那一手。

## 新增：AI 故意俗手

和「故意失误」是两回事：失误是明显的错招（红色「恶」），俗手是看着自然、其实悄悄吃小亏的棋——优先选人类模型自己最想下的那一手，所以特别像真人会下的棋。在 AI 托管设置里按黑方 / 白方单独开启（和其他设置用分隔线分开，不混在一起），只对全实力 AI 生效；每局随机 1～2 手，只在稳赢时下，胜率和目数都有底线，局面没定型的地方不碰。那颗子标白色书法「俗」，复盘里专门标记、不算恶手。

## 全屏模式补上悬浮标签

全屏模式下点选落子点，棋盘上方现在也会浮出和普通模式一样的标签（一选紫/淡黄、双一选橙、二选三选白、定局时红「绝」/蓝「定」），悬浮不挡视线，带动画；同一结论在棋盘下方的信息条里也有一份常驻小标签，抬头看浮标、落点看信息条，都能确认选中的是第几选。

## 其他

- 书法字体子集扩到五个字（绝、定、恶、俗、销），体积只多了约 2 KB。
- 复盘的整场分析现在顺带记录每手的地盘归属，「定」的判定在复盘里也能跑；检测出的标记会存进棋谱，下次打开直接显示。
