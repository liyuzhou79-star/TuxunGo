# TuxunGo 1.0.0

TuxunGo 正式版来了。免费、开源、完全离线：KataGo 引擎和模型都装在手机里，不用注册，不用联网，随时随地开一局。

## 新功能

- **对局复盘**：对局结束后点「查看复盘」，整场逐手分析一次算完。胜率和目差双曲线、拖动进度回放每一手，自动标出恶手、妙手和全场波动最大的一手；一方胜率超过 75% 的时段在图上用绿色标出。黑白视角随时切换，还能从任意一手「继续下」。
- **棋谱库**：可以建文件夹收藏棋谱。AI 对局、双人对局、摆棋开局打完的棋都能存，点开就进复盘，分析结果会缓存，下次打开秒看。
- **AI 托管**：任何对局中都能呼叫 AI 接管黑方或白方，双方可以各用不同的模型和强度对打（比如一个用内置模型、一个用你导入的大模型），局内随时切换。导入模型时可以起名字，内置模型也能改昵称，模型库最多放 99 个。
- **全屏模式**：对局右上角进全屏，棋盘放到最大，只留分析和形势判断，适合观战 AI 对决。

## 优化

- 顶部实时形势改为固定位置显示，数字更新时棋盘不再被挤得上下跳。
- 分析和形势判断面板的展开方式改稳，不再出现文字和按钮重叠。
- 悔棋更跟手：AI 对局中悔棋会自动暂停，不会刚退完又立刻被 AI 下回去。
- 形势判断和数目估算口径统一，死子计入对方地盘，数目更准；终局数目可以点棋块整块改判死活。

## 说明

- 本版起改用正式签名：从 0.1.0 测试版升级的用户需要先卸载再安装一次，之后所有版本都可以直接覆盖升级。
- 内置 10 层 KataGo 模型开箱即用；想要更强的棋力，可以在模型库导入更大的 KataGo 官方模型（.bin.gz / .txt.gz），导入时会自动校验文件并试跑引擎，坏文件进不了库。
