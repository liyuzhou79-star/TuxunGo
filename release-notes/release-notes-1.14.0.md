# TuxunGo 1.14.0

## 新功能

- **我的数据**：主页新增统计页——对局总览（局数、总手数、平均手数、最长一局）、黑白胜负分布、各模式局数、最近对局手数图，还有死活题与猜一选的训练进度。全部在本机根据棋谱库统计，不联网、不上传。
- **模型测速**：模型库里每个模型都能测速——在 19 路空盘上实测一手 200 访问的思考速度（访问/秒），挑模型、比强弱时心里有数。
- **检查更新**：设置里新增手动「检查更新」，查一下 GitHub 上有没有新版本。这是 App 唯一的联网功能：只有你点它的时候才联网一次，对局和分析永远离线。

## 修复与优化

- **翻转棋盘排版修复**：白方视角（翻转）时棋盘面几何算错，木纹底板缩成左上角一小块、坐标还重影——已按翻转后的实际四角重算，翻转时棋盘、坐标、边框全部正常。
- **妙手判定收紧**：以前只要下出 AI 一选就算妙手，安静局面里满屏都是。现在还要这一选明显甩开其他候选（胜率拉开 5% 以上）才算——妙手重新变得有含金量。旧棋谱没记录候选差距，复盘时妙手会变少，恶手和关键手不受影响。
- **数目判断重做**：死子改成整块棋一起判（看整组棋的平均归属），不再被单个点的噪声带偏；个别被彻底吃死的子（归属超过 90%）单独判死。空地按整片区域的平均归属先判，成片的地盘里个别读数弱的点不会再被漏数。形势行、形势详情、形式判断面板和终局数目的死子建议现在用同一套判断，结果一致也更准。
