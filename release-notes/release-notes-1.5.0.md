# TuxunGo 1.5.0

## 新功能与优化

- **再来一局**：对局结束弹窗新增「再来一局（相同设置）」，不用回主页重新设置，同样的盘面、让子、棋钟直接再战。
- **全屏模式胜率条**：全屏观战 / 对局时棋盘下方多了一条胜率条，黑白形势一眼可见，不用只看数字。
- **棋谱库文件夹计数**：文件夹筛选标签上直接显示每个文件夹里的棋谱数量，收藏分布一目了然。
- **死活题解题计时**：解开一道题会显示本次用时和这道题的历史最佳用时，刷题时能看到自己有没有变快。

## 说明

- 本版可直接覆盖安装在 1.0.8 及之后的版本上。正式版将使用独立的发布签名，发布时再卸载最后一次即可。
