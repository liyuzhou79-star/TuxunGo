# TuxunGo 2.65.0

这一版只做一件事：把棋盘上的候选标记整个推倒重做——样式和配色都换掉。

## 标记样式重做

- **扁平纯色，不再有玻璃珠质感**：之前的标记带渐变、高光、投影，看着像一颗颗玻璃珠扣在棋盘上。这一版全部去掉：平涂的纯色圆点、一圈细边、中间是名次数字，像直接印在棋盘上的标记，干净利落。
- **配色重新定义**：
  - **人类一选：紫色**
  - **AI 一选：淡黄色**
  - **两个一选落在同一点：橙色**
  - **二选、三选、四选及以后：白色**
- **同点只画一个颜色**：AI 的名次和人类的名次落在同一点时，按优先级只保留一个：双一选（橙）> 人类一选（紫）> AI 一选（淡黄）> 白色名次，不会再出现两个标记叠在一起的情况。
- **悬浮标签同步**：点选落子点时棋盘上方浮出的小标签用同一套颜色和优先级——紫色「人类一选」、淡黄「一选」、橙色「双一选」、白色「二选 / 三选」，定局手仍是红色实心「绝」。
- 「绝」字徽章同步改成扁平红色圆盘，与新标记风格统一。
