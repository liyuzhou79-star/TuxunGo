# TuxunGo 2.68.0

这一版是稳定性版：不加新功能，把容易出错的角落逐个查了一遍，并补上自动化测试把行为钉住。

## 稳定性

- **错误处理全量审计**：通查了全 App 的失败分支，确认没有任何地方靠「报错文字长什么样」来决定下一步——这种写法在文案调整或翻译后会悄悄失效。所有失败都按类型处理：网络请求看 HTTP 状态码、引擎通信看 GTP 协议标记、分析结果看结构化错误字段、文件读写看异常类型。
- **地盘估算补测**：形势判断和终局数目背后的地盘/死子计算此前没有专门测试。这次补齐：空棋盘、整块实地、死子归对方、活子不算地、混在大块里的单颗死子、显示锐化的进/出边界，都钉成了测试。
- **对局数据存取往返补测**：复盘数据的存与读做了往返验证，包括「故意恶手」标记、老版本（没有该标记时）棋谱数据的兼容读取、稀疏记录的回合号保持。
- **长方形棋盘补测**：非正方形棋盘（比如 13×9）的角上提子、停一手轮换，补上了规则测试。

这些测试从这一版起会随每次构建自动运行，钉住的行为不会再悄悄坏掉。
