# TuxunGo 2.72.0

## AI 分析开始标「俗手」了

分析的候选着点里，经常藏着一手「俗手」：看着最自然、很多人顺手就会下，其实悄悄亏掉几个点的胜率——赢棋赢得慢、输棋输得快，往往就是输在这种棋上。这一版起，AI 分析会把这一手指出来：

- 候选点角上多一个白色小圆盘，书法体「俗」字，和棋子上的徽章一个样式；
- 分析面板的候选列表里，那一手后面也会写上（俗）；
- 单次分析、连续分析、自动分析都会标，全屏模式的棋盘上同样有；
- 挑选标准和故意俗手是同一套：不是一选、胜率亏 2%～9%（亏得再多就是恶手了），人类模型最爱下的那一手优先——越是「大家都会下」的，越优先标出来。

## 故意俗手去掉全部条件

上一版的 AI 故意俗手有不少限制：只有全实力 AI 能开、只有稳赢时才下。这一版按「随时能开、任何条件能开」改了：

- 定级 AI、模拟人类落子的一方也能开，开关不再置灰；
- 不再要求稳赢：领先、落后、局面未定型，都可能下出俗手；
- 剩下的只有俗手本身的定义（亏 2%～9%）和每局 1～2 手的量——落后时也下，AI 会输得更快一点，这是把条件全去掉的自然结果，开之前心里有数就行。

## 其他

- 判定核心和上一版相同：红色「绝」全局定局、蓝色「定」局部定型、绿色「销」消劫，规则没有改动。
