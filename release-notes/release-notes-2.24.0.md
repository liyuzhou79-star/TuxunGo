# TuxunGo 2.24.0

## 新功能

- **猜一选用自己的棋谱出题**：猜一选训练新增「题目来源」——选「我的棋谱」后，题目会从你棋谱库里的对局中随机抽取一个中盘局面，让你猜当时的 AI 一选。用自己下过的棋出题，哪一手是当时没看到的好点，下完立刻见分晓。让子棋、摆棋局的题目也会带上初始局面一起分析；这类题目的错题暂不存入错题本（错题本的格式是从空棋盘重演的）。
- **终局自动存图（可选）**：设置 → 对局与操作里新增「终局自动存图」开关。打开后，每局结束时会自动把终局局面图存进相册（带比赛结果字幕），不用再手动点保存。默认关闭。

## 优化

- **走势小图可点开大图**：对局里的胜率走势小图现在可以点，弹出大图：黑方胜率红线、目数差黄线，还有全场关键手标记，和复盘页同款图。
- **棋谱库缩略图可点**：点棋谱左边的终局缩略图，直接打开这局的复盘，少点一次。
