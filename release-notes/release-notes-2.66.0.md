# TuxunGo 2.66.0

这一版不加新功能，专门做流畅度和省电优化：对局页几个一直在重复计算、重复绘制的地方，都改成算一次、用缓存。

## 优化

- **面板不再每秒重算全盘**：形势判断面板打开时，地盘估算、死子统计、比分和可信度原本会跟着棋钟的跳动每秒把整张棋盘重算一遍；现在改为每个局面只算一次并缓存，数字不变、开销大减，AI 分析面板的地盘估算同理。
- **棋盘不再每帧重画**：最后一手棋子上的蓝色圆圈原本带一个不停呼吸的动画，它会让整个棋盘画面每帧重画、对局全程不停歇——现在圆圈改为常亮标记（落子瞬间的涟漪动画保留），长时间对局更省电，操作也更跟手。
- **「绝」判定缓存**：点选棋子、看分析面板时不再反复跑整盘扫描判定是否定局，结果先缓存好直接用。

这些改动不改变任何判定结果和显示数字，只是把重复劳动去掉：该算的算一次，不该重画的不重画。
