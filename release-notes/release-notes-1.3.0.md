# TuxunGo 1.3.0

## 新功能与优化

- **死活题新增「大龙紧气」**：一条看着气很多的大龙，其实只剩一口气，而且藏在棋形正中间。题库现有 5 题，解法全部经过规则推演逐手验证。
- **棋谱库搜索**：棋谱多了按标题或类型（人机对弈 / AI 对 AI / 双人对弈等）直接搜，收藏多了也不怕找不到。
- **复盘长按连跳**：「上一手 / 下一手」按钮按住不放会连续快进快退，长棋谱不用一下下点。
- **形势详情弹窗**：对局页点形势行，弹出完整的估算明细——胜率、目差、双方活子与空、估算死子，一目了然。
- **猜一选难度可调**：新增快速 / 标准 / 深度三档（每题分析量不同），选择会被记住；快速档出题更快，深度档的一选更权威。
- **仓库说明更新**：README（中英双版）补齐了训练模式与复盘分支的介绍。
