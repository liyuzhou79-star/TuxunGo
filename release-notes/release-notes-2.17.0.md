# TuxunGo 2.17.0 更新说明

## 新功能

- **一色棋**：开局设置里新增开关。双方棋子都显示黑色，全靠记忆下棋，练记谱和棋感；对局顶栏点「显色」可以偷看一眼真实颜色，再点「一色」切回来。
- **手数显示**（设置里开启）：在棋子上标出每一手是第几手落的，复盘和读谱都更方便。
- **AI 一句话讲棋**：AI 分析结果下面多了一句人话点评——谁占优、领先多少、一选是不是明显强于其他着法，一眼看懂局面。
- **局面图保存到相册**：对局结束弹窗和复盘页新增「保存到相册」，局面图直接存进相册（Pictures/TuxunGo），不用再绕分享。

## 界面

- **主页瘦身，新增二级菜单**：主页只留开局设置、开始按钮、训练与工具两个入口和最近棋谱；猜一选、死活题收进「训练」页，棋谱库、我的数据、AI 模型、实体棋盘棋钟收进「资料与工具」页。
- **统一顶栏**：各页改用统一的顶栏样式（‹ 返回 + 标题 + 一行小字说明），不再是只有一个「返回」的光秃秃按钮。
- **一批交互细节**：主页卡片、模式选项和开始按钮有了按压回弹反馈，选中的模式卡带对勾徽章；分析/判断进行中按钮内嵌转圈；候选着法圆盘按名次逐级变小，一选最醒目；读秒最后 10 秒每秒滴答提醒（对局棋钟和实体棋盘棋钟都有）；实体棋钟按钟时面板会闪一下蓝框；对局结束弹窗关掉后，顶栏留一个「结果」按钮随时重开；死活题点错时棋盘会轻轻抖一下。

## 其他

- 新手指南文案同步到新的主页结构。
