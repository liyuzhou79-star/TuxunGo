# TuxunGo 2.67.0

这一版继续做响应速度优化：给分析加了一层局面缓存，来回翻看局面时不用再等引擎重算。

## 优化

- **分析过的局面直接秒出**：最近 12 个局面的分析结果会被记住。悔棋后回到刚才的局面、撤销又重下、来回翻看几个关键位置——只要是分析过的同一个局面，结果立刻显示，不再重新等引擎算一遍。
- **缓存不会串味**：缓存的钥匙里包含棋盘大小、贴目、当前用的模型、是否开了人类选点、摆棋的底子——任何一项不同都是不同的缓存，绝不会把强力模型的结果当成轻量模型的拿出来。
- **深度不糊弄**：缓存里记着每个结果当时算了多深。之前只做过快速分析的局面，再点深度分析时仍会认真深算，不会拿浅结果顶替。

配合上一版的面板计算缓存，对局里反复看几个关键局面的操作会明显更跟手。
