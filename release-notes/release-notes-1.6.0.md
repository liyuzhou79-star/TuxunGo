# TuxunGo 1.6.0

## 新功能与优化

- **死活题新增「做活」题**：题库第一次出现防守题——这次你执白，在直三眼位里找做活的要点。占住中间把大眼分成两个真眼就活了；下错位置会被黑棋扑入回提整块提掉。题库现有 6 题，解法全部经过规则推演逐手验证。
- **对局自动分析强度可调**：设置里新增「对局自动分析」三档（快速 / 标准 / 深度）——控制对局时后台预计算每一手胜率的深度。快速更省电，深度让终局复盘的数据更准。
- **棋谱一键复制**：棋谱库里每张卡片多了「复制」，同盘棋想存两份、或者拿副本去试下分支时不用重打一遍。
